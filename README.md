# Portfolio Website

Portfolio website responsif yang dibuat dengan React.js dan Vite.

## Fitur

- ✅ Responsive design untuk semua device
- ✅ One page application dengan smooth scrolling
- ✅ Modern dan clean design
- ✅ Data terpusat dalam satu file (database.js)
- ✅ Fast loading dengan Vite
- ✅ SEO friendly

## Cara Menggunakan

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Jalankan development server:**
   ```bash
   npm run dev
   ```

3. **Build untuk production:**
   ```bash
   npm run build
   ```

## Kustomisasi

Untuk mengubah data portfolio, edit file `src/database.js`:

- **Personal Info**: Nama, email, bio, dll
- **Skills**: Frontend, backend, tools
- **Projects**: Daftar project dengan gambar dan link
- **Experience**: Riwayat pekerjaan
- **Services**: Layanan yang ditawarkan

## Struktur File

```
src/
├── components/         # Komponen React
│   ├── Header.jsx     # Navigation header
│   ├── Hero.jsx       # Hero section
│   ├── About.jsx      # About section
│   ├── Skills.jsx     # Skills section
│   ├── Projects.jsx   # Projects section
│   ├── Experience.jsx # Experience section
│   ├── Services.jsx   # Services section
│   ├── Contact.jsx    # Contact section
│   └── Footer.jsx     # Footer
├── database.js        # Data portfolio
├── App.jsx           # Main app component
├── main.jsx          # Entry point
└── index.css         # Global styles
```

## Menambah Gambar

1. Letakkan gambar di folder `public/`
2. Update path di `database.js`
3. Contoh: `/avatar.jpg`, `/project1.jpg`

## Deployment

Website ini bisa di-deploy ke:
- Netlify
- Vercel
- GitHub Pages
- Atau hosting lainnya

Jalankan `npm run build` untuk membuat build production.
